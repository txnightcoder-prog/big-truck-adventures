# BIG TRUCK ADVENTURES
## Google Gemini — Character Image Generation Prompts

---

## HOW TO USE

1. Go to gemini.google.com (or Gemini Advanced)
2. Click the image generation option
3. Paste each prompt below exactly
4. Save each image — these become your character reference sheets for Roxi.ai
5. Generate 3–4 variations of each character and pick the best one
