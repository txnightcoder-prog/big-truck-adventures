# Big Truck Adventures

> A kids cartoon show for ages 2–6 — @TxNightcoder on YouTube

Bentley, Jensen, Russell, and baby Emery go on big truck adventures every episode — learning letters, numbers, shapes, colors, and teamwork along the way.

## Live Site
Hosted on GitHub Pages: https://txnightcoder-prog.github.io/big-truck-adventures

## YouTube Channel
https://www.youtube.com/@TxNightcoder

## Deploying Updates
1. Edit `index.html`
2. `git add . && git commit -m "update site"`
3. `git push origin main`
GitHub Pages auto-publishes within ~60 seconds.
